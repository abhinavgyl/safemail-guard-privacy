SafeMail Guard

Privacy Policy

Last updated: September 20, 2026

SafeMail Guard is a Chrome extension designed to help users identify potential spam, phishing, suspicious links, and other potentially harmful indicators in Gmail.

This Privacy Policy explains what information SafeMail Guard processes, how it is used, and how the extension is designed to protect user privacy.

Privacy-first design: SafeMail Guard is designed to analyze the Gmail message currently being viewed without requiring access to the user's Google account credentials or continuously scanning the user's inbox.

1. Information SafeMail Guard Processes

When a user opens a Gmail message, SafeMail Guard may process information visible within that message, including:

  • Sender name and sender email address
  • Email subject
  • Visible email content needed for security analysis
  • Links contained in the currently viewed message
  • Visible sender and message security indicators
  • Information needed to identify potentially suspicious patterns

This information is processed to provide the extension's spam, phishing, sender, and link-risk analysis.

2. Local Processing

SafeMail Guard is designed to perform its primary email analysis locally in the user's browser.

The extension does not require the user to provide Google account credentials to SafeMail Guard.

SafeMail Guard is not designed to continuously scan the user's entire Gmail inbox. Its primary analysis is associated with the Gmail message currently being viewed.

3. Local Learning

SafeMail Guard may allow the user to mark a sender as safe or report a sender as spam or phishing.

These classifications are stored locally in the browser using Chrome extension storage and are used to personalize future analysis on that device.

A user's local classifications are not intended to be transmitted to the developer as part of the current local learning functionality.

4. Email Content and Attachments

SafeMail Guard is designed to use information from the currently viewed Gmail message for security analysis.

SafeMail Guard does not intentionally upload the user's email body or email attachments to the developer's personal website or GitHub Pages privacy-policy site.

5. Google Web Risk

SafeMail Guard does not use Google Web Risk.

6. Community Reputation

The SafeMail Guard project may support an optional community reputation feature in a future version.

Any future community reputation functionality will be subject to the privacy disclosures and technical implementation applicable to that version before it is enabled.

The current release does not operate a live community reputation server.

7. Information We Do Not Intentionally Collect

SafeMail Guard is not designed to intentionally collect:

  • Google account passwords
  • Gmail login credentials
  • Email account passwords
  • Entire Gmail inboxes
  • Email attachments for storage by the developer
  • Personal information for advertising purposes

8. Data Sharing and Sale

SafeMail Guard does not sell users' email content or personal information.

The developer does not intentionally provide users' email content to advertisers for advertising purposes.

9. Third-Party Services

The privacy-policy website is hosted using GitHub Pages.

GitHub Pages is separate from the SafeMail Guard browser extension. Visiting this privacy-policy website is not required for the extension to perform its local Gmail analysis.

10. Security

SafeMail Guard is designed to minimize the amount of information that leaves the user's browser and to avoid unnecessary permissions.

No security system can guarantee complete protection against every spam, phishing, or malicious message. Users should review suspicious messages carefully and avoid providing sensitive information to untrusted senders.

11. Changes to This Privacy Policy

This Privacy Policy may be updated when SafeMail Guard's functionality or data practices change.

The "Last updated" date at the beginning of this policy will be changed when material updates are made.
