# SafeMail Guard — Privacy Policy

This repository hosts the public privacy policy for **SafeMail Guard**, a Chrome extension designed to help users identify potential spam, phishing, and suspicious links in Gmail.

## Privacy Policy

The current privacy policy is available at:

https://abhinavgyl.github.io/safemail-guard-privacy/

## About SafeMail Guard

SafeMail Guard analyzes the Gmail message currently being viewed by the user and provides risk indicators, sender information, suspicious-link warnings, and optional local learning features.

The extension is designed with a privacy-first approach.

### Current privacy principles

- Email analysis is performed locally in the browser where possible.
- SafeMail Guard does not require access to the user's Google account credentials.
- SafeMail Guard does not intentionally collect or sell email content.
- Local sender classifications and preferences are stored locally in the browser.
- The extension does not use Google Web Risk.
- The current release does not operate a live community reputation server.
- SafeMail Guard is currently designed for Gmail.
